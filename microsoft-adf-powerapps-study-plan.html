Microsoft Data Factory + Power Platform Expert - Study Plan

11 weeks, three exams in sequence: DP-700, AB-400, AB-100. Weekdays ~2-3h, one long weekend block. Exam facts verified on learn.microsoft.com on 2026-10-09. Checkboxes and ratings save in this browser.

Overview

Azure fundamentals, identity, networking and IaC are skipped. The time goes to Fabric Data Factory and Spark/KQL authoring, then Dataverse and Power Platform development, then agentic solution architecture.

Catalog changes that shaped this plan (checked 2026-10-09):
  • No exam tests classic Azure Data Factory any more. DP-203 (Azure Data Engineer Associate) retired on 2025-03-31. Data Factory is now examined only as Data Factory in Microsoft Fabric in DP-700: pipelines, Dataflow Gen2, Apache Airflow jobs, mirroring, shortcuts. DP-700 has no classic-ADF objective. Classic ADF shows up only as a tool choice in DP-750 (Azure Databricks Data Engineer). This plan covers classic ADF in one optional bridge session (Week 1 weekend), because it matters at work, not on the exam.
  • PL-600 (Power Platform Solution Architect Expert) retired on 2026-06-30 and PL-200 (Functional Consultant) retired on 2026-08-31. There is no longer a "Power Apps expert" certification. Microsoft names AB-100: Agentic AI Business Solutions Architect Expert as the flagship expert-level next step for PL-600 holders. Microsoft says it is "not a direct replacement" and its scope is much broader: Copilot Studio, Foundry, Dynamics 365 and Power Platform.
  • AB-100 prerequisite: you pass AB-100 and hold one listed associate certification. Microsoft Certified: Power Platform Developer Associate is on the list. That is the developer path.
  • PL-400 becomes AB-400 on 2026-10-16. PL-400 registration closes that day, and existing PL-400 bookings must be sat by 2026-10-30, which is too soon to prepare. So the associate exam is AB-400, which leads to the same Power Platform Developer Associate certification. The study guide is published, but Microsoft Learn has no AB-400 learning paths yet, so this plan uses the PL-400 paths plus docs for the new objectives: code apps, MCP, Foundry agents.

That also gives AB-400, which launches 2026-10-16, four weeks for its practice material and learning paths to appear. AB-400 must come before AB-100: the associate is the expert prerequisite, and AB-100 assumes the Power Platform, Copilot Studio and ALM depth that AB-400 builds.

Why 11 weeks (not 8-10)

Before the retirements this was two Power Platform exams. Now it is three exams: the expert credential needs AB-100 plus an associate, and DP-700 is separate. At ~2.5h x 5 weekdays + ~5h weekend = ~17h/week:

  • DP-700: 3 learning weeks + 1 review (~68h). Spark, KQL and Real-Time Intelligence are new, but the cloud and data concepts are not.
  • AB-400: 3 learning weeks + 1 review (~68h). This is the biggest gap: Dataverse, plug-ins, PCF, client API, Power Fx, all from zero.
  • AB-100: 2 learning weeks + 1 review (~51h). Architecture is a strength, and Weeks 5-8 already cover most of the Power Platform material.

Compress to 10: if you score 80%+ on the DP-700 practice assessment in the Week 3 weekend, book the exam then and start Week 5 a week early.

Format and scoring

  • Passing score: 700 on a 1-1000 scale. It is scaled, not a percentage (scoring and score reports).
  • Duration: associate and expert exams without labs get 100 minutes (120 min seat time). Exams that may contain labs get 120 minutes (140 min seat time). The exact time is shown when you register. A 5-minute break allowance is built in, but the clock keeps running (exam duration and experience).
  • Question types: multiple choice, best answer, active screen, build list, drag and drop, hot area, case studies, problem-solution sets (no going back), and possibly labs. You can mark questions for review; after a break you cannot return to earlier questions.
  • Microsoft Learn is available in the exam in a split pane on role-based exams. Microsoft says it is for look-ups only; you won't have time to research every question.
  • If the exam is not in your preferred language you can request an extra 30 minutes.

Cost, scheduling, retakes

  • Cost: US$165 per exam in the United States (Microsoft exam-pricing data; varies by country; taxes extra).
  • Schedule from the exam page ("Schedule exam") through Pearson VUE. Microsoft recommends registering with a personal Microsoft account, not a work account, so records survive a job change.
  • Online (OnVUE): webcam and microphone proctoring. Run the required system test on the same computer and network. Use a personal computer, not a locked-down work laptop. Phone out of reach (online exam rules).
  • Test center: pick one when you book via Pearson VUE for Microsoft.
  • Retakes: wait 24 hours after a first failure; at most 5 attempts per exam in 12 months (retake policy). Check offers / Exam Replay before booking.
  • Request accommodations if needed.

Renewal

  • Associate and expert certifications expire annually. Renew free by passing an online, unproctored, open-book renewal assessment on Microsoft Learn.
  • The renewal window opens six months before expiry. Passing extends the certification one year from the expiration date. Unlimited renewal attempts before expiry.
  • Renewal details

AI integration fundamentals

Shared across all the study guides. No model training or data science: you call a model over HTTPS and engineer the software around it. Most of it is ordinary API work; the seven areas below are what is different, because an LLM is a probabilistic component, not a deterministic API.

SameWhat is just API integration

REST/SDK calls, auth, retries, timeouts, rate limits, streaming (SSE), cost metering. MCP is JSON-RPC with a tool/resource schema; an MCP server is a small service exposing your existing APIs as tools.

Tasks

  • Make a first Messages API call with streaming; read the usage block (input/output/cache tokens)
  • Read the MCP architecture overview: hosts, clients, servers, tools, resources, prompts

  • Streaming messages
  • MCP architecture overview

Names, descriptions and input schemas decide whether the model picks the right tool with the right arguments. API design for a non-human caller.

  • Rewrite one vague tool description and compare call accuracy before and after

Materials

  • Tool use overview

Model requests a tool, your code runs it, the result goes back, repeat. Stop conditions, structured errors the model can recover from, parallel tool calls.
