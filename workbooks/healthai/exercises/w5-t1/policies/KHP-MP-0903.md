# KHP-MP-0903 Outpatient physical therapy

## Overview

This medical policy describes when Kestrel Health Plan covers outpatient physical therapy for members. It applies to commercial, Medicare Advantage and Medicaid managed care lines unless a state rule requires otherwise. Coverage requires prior authorization.

### Documentation

Submit clinical notes for rehabilitation covering the last six months, the results of prior treatment, and an attestation from the ordering clinician. Missing documentation results in a request for information, not a denial.

## Exclusions

Requests for rehabilitation that are investigational, cosmetic or duplicate a study performed in the last twelve months are not covered under this policy.
