# KHP-MP-0101 Infliximab for inflammatory bowel disease

## Overview

This medical policy describes when Kestrel Health Plan covers infliximab for inflammatory bowel disease for members. It applies to commercial, Medicare Advantage and Medicaid managed care lines unless a state rule requires otherwise. Coverage requires prior authorization.

### Documentation

Submit clinical notes for infliximab covering the last six months, the results of prior treatment, and an attestation from the ordering clinician. Missing documentation results in a request for information, not a denial.

## Exclusions

Requests for infliximab that are investigational, cosmetic or duplicate a study performed in the last twelve months are not covered under this policy.
