# KHP-MP-0520 Bariatric surgery

## Overview

This medical policy describes when Kestrel Health Plan covers bariatric surgery for members. It applies to commercial, Medicare Advantage and Medicaid managed care lines unless a state rule requires otherwise. Coverage requires prior authorization.

### Documentation

Submit clinical notes for bariatric covering the last six months, the results of prior treatment, and an attestation from the ordering clinician. Missing documentation results in a request for information, not a denial.

## Exclusions

Requests for bariatric that are investigational, cosmetic or duplicate a study performed in the last twelve months are not covered under this policy.
