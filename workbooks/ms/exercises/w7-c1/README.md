# ms/w7-c1: PCF asset tag input with validation, debounce and clean teardown

Type: coding. Estimate: 2-3 h. Exam: AB-400 - Extend the user experience (25-30%): create and use Power Apps component framework (PCF) code components.

## Scenario

Tailspin Field Services tracks 40,000 pieces of field equipment in a model-driven app (Dataverse table
`tsp_asset`). Technicians type asset tags by hand from scratched metal plates, and the `tsp_assettag`
column is full of junk: `tsp123456`, `TSP 123456`, `TSP-12345`. Duplicate-detection and the nightly sync to
the maintenance system both key on this column, so every bad value becomes a ticket.

The platform team wants a PCF field component bound to the column that:
normalizes what technicians type, refuses to write invalid tags, does not hammer the form with an
`OnChange` on every keystroke, and respects read-only forms and field-level security. A previous attempt
(the starter) notifies the framework on every keystroke and leaks event handlers when the form is closed.

## Your task

The project is laid out like `pac pcf init` output, minus `pcf-scripts` (so it runs offline):

```
AssetTagInput/ControlManifest.Input.xml   manifest (finish it)
AssetTagInput/index.ts                    the control (implement it)
AssetTagInput/css/AssetTagInput.css       styles (given)
AssetTagInput/generated/ManifestTypes.d.ts  IInputs/IOutputs (given; normally generated by `npm run build`)
tests/                                    visible jest tests + a fake context
```

1. Finish the manifest: add the `tagPrefix` (`SingleLine.Text`) and `debounceMs` (`Whole.None`) properties
   with `usage="input"`, and register the stylesheet as a `css` resource.
2. Implement `AssetTagInput` (a `ComponentFramework.StandardControl<IInputs, IOutputs>`) to this contract:
   - **Format.** A valid tag is `<PREFIX>-<6 digits>`. `PREFIX` is `tagPrefix` upper-cased; when it is null
     or blank use `TSP`. The prefix is literal text, not a regex (a prefix of `A.B` must not match `AXB`).
   - **Normalization.** Remove all whitespace and upper-case. If the result is `<PREFIX><6 digits>` (dash
     missing), insert the dash. After a successful commit the input shows the normalized tag.
   - **Commit rules.** On `input` events, commit after `debounceMs` of quiet (default 400 ms when null or
     negative). On `blur`, commit immediately and cancel any pending debounce. A commit of:
     - blank text sets the value to `undefined` (clears the column);
     - a valid tag sets the value to the normalized tag;
     - anything else keeps the last value and shows the error state (below).
     Call `notifyOutputChanged()` only when the committed value differs from the last known value.
   - **getOutputs** returns `{ assetTag: <last known value> }` (`undefined` clears the column).
   - **updateView** never calls `notifyOutputChanged`. It re-reads `tagPrefix`/`debounceMs`, sets
     `input.disabled` when `context.mode.isControlDisabled` is true or the bound column's
     `security.editable` is `false` (field-level security), and when `assetTag.raw` differs from the last
     known value it adopts it (null or "" means `undefined`) and shows it, unless the user is mid-edit
     (a debounce is pending).
   - **DOM.** Render a root `div.tsp-assettag` containing the `input` and a `div.tsp-error` with
     `role="alert"`. In the error state the root has class `tsp-invalid`, the error element is visible
     (`hidden === false`) and its text contains an example such as `TSP-123456`; otherwise it is hidden.
   - **destroy** removes every event listener the control added, cancels a pending timer (no late
     `notifyOutputChanged`), and removes its DOM from the container.

## Acceptance criteria

- `make test` passes; the hidden tests cover lifecycle ordering, no echo from `updateView`, null values,
  debounce/blur timing, invalid input, custom and regex-special prefixes, disabled and field-security states,
  listener/timer leaks after `destroy`, and manifest structure.
- The manifest is well-formed, `control-type="standard"`, declares every property in `IInputs` with the
  right `usage` and `of-type`, and registers the code and css resources that exist on disk.
- No `any` casts in `index.ts`; strict TypeScript compiles.

## How to run

```
make setup     # npm install (jest, ts-jest, jsdom, PCF typings)
make test      # visible tests
make clean     # remove node_modules
```

Then from the workbooks root: `/grade ms/w7-c1`.

Notes: real PCF projects build with `pcf-scripts` (`npm run build`, `npm start watch` for the test harness)
and ship with `pac pcf push` or inside a solution. The typings here are the real
`@types/powerapps-component-framework` package; only `ManifestTypes.d.ts` is hand-shipped.
