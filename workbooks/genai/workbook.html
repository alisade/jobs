GenAI / Agentic AI Engineer workbook

Hands-on coding, troubleshooting and design exercises set at Kestrel Outfitters (a fictional outdoor and home-goods retailer with 140 stores and a web shop) building a shopping assistant: React + TypeScript front end, FastAPI services, the agent, evals and guardrails, microservices. One tab per study week, plus weekly self-exams. Everything grades locally and offline: models are scripted fakes or recorded streams, no API keys, no cloud accounts.

Scores update after /grade; reload the page. Grades come from ../grades/grades.js, written by tools/update_grades.py when you run /grade genai/<id> in Claude Code from the workbooks/ folder. Quiz answers save in this browser (localStorage key wb-genai-v1).

How to work an exercise

  1. Check tools once: python3, uv, node 22, jq (tools/doctor.sh).
  2. Open the week tab, read the card, then the folder README.
  3. cd genai/exercises/<id> && make setup (first run installs the shared toolchain into genai/_env and genai/.venv), solve it, make test, fill in ANSWER.md.
  4. From workbooks/: /grade genai/<id>. Reload this page.
  5. make clean. Retry as often as you like; every attempt is kept.

Do not open .grading/ before you submit. Pass mark 70/100. Troubleshooting is graded mostly on root cause and evidence; design exercises are graded by rubric only (the grader reports 0/0 tests and the automated row does not apply).

How the local stand-ins work

  • Front end: React 18 + TypeScript with jest, ts-jest and React Testing Library on jsdom; model streams are recorded Server-Sent Events pushed chunk by chunk.
  • Back end: FastAPI, Pydantic 2 and SQLAlchemy 2.0 on SQLite, tested with pytest, TestClient and httpx ASGITransport.
  • Models: scripted fake clients that return tool calls and text in the Messages API shape, plus fake clocks for retries, timeouts and TTLs.
  • MCP: the official Python SDK with an in-memory client session.
  • Contracts: OpenAPI exported from FastAPI, TypeScript types generated with openapi-typescript and checked with tsc.
  • Troubleshooting exercises ship an evidence/ bundle (pages, logs, traces, usage exports) and a make demo that reproduces the symptom.

Streamed shopping-assistant panel (React + TypeScript)

coding 2-3 h

genai/w1-c1 · React and TypeScript front end

Scenario. Kestrel Outfitters' assistant gateway streams answers as Server-Sent Events. The prototype panel worked in the demo but behind the CDN and load balancer it garbles JSON, drops words, keeps typing forever when a connection drops, and cannot be stopped. Make it production-ready for the beta.

Task

  • Incremental SSE parser that is correct for any chunking, CRLF and bare CR, comments, multi-line data and ids
  • fetch transport with a stream reader, split multi-byte UTF-8, typed HTTP errors, reader cancel on early stop
  • Hook with idle/streaming/done/stopped/error, stop, retry, conversation id, no stale updates
  • Panel with AI disclosure, Stop, status line, live region, product cards, error alert, human handoff

Acceptance criteria

  • Every chunking of the recorded streams renders identical text and cards
  • Stop and unmount abort the request; later chunks are ignored
  • Error events, drops, early end and 429 show the specified messages; Try again works
  • Malformed or unknown events never crash the panel
