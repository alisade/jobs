# CHG-8812 - Move storefront to the new edge proxy tier

Window: 2026-11-04 22:00-23:30 PT. Status: completed.

- Replaces the legacy CDN behaviour for /api/* with the new edge proxy tier.
- Default upstream idle timeout: 15 s (legacy: 120 s). "Clients should not hold idle connections."
- Response buffering disabled for text/event-stream (verified in staging).
- Rollback: route /api/* back to the legacy CDN (about 10 minutes).
