# Curveballs (minute 30)

1. "A product team shipped a workflow that loops: every update it makes to an opportunity triggers
   itself again. It is doing 400 executions a second. What stops it, and who gets paged?"
2. "The renewals team needs to change a workflow while 30,000 executions of the old version are
   waiting on 120-day timers. How does that work?"
3. "The sales assistant agent wants to start the discount approval workflow. What does the agent get to
   do, what does it not get to do, and how does the approver know an agent was involved?"
4. "Your service is down for 20 minutes. What happens to the stage-change events that should have
   triggered workflows in that window?"
