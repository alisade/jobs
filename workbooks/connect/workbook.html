Amazon Connect workbook

Hands-on coding, troubleshooting and design exercises for the Enterprise Help Desk Transformation at Larkspur Financial Group (fictional), one tab per study week, plus weekly self-exams and two timed mocks. Everything grades locally: no AWS account calls, no Docker.

Scores update after /grade; reload the page. Grades come from ../grades/grades.js, written by tools/update_grades.py when you run /grade connect/<id> in Claude Code from the workbooks/ folder. Quiz answers and mock results save in this browser (localStorage key wb-connect-v1).

How to work an exercise

  1. tools/doctor.sh connect once: node 22, uv, jq; the Java exercise also needs JDK 21 + Maven.
  2. Open the week tab, read the card, then the folder README.
  3. cd connect/exercises/<id> && make setup (first run installs the shared toolchain into connect/_env), solve it, make test, fill in ANSWER.md.
  4. From workbooks/: /grade connect/<id>. Reload this page.
  5. make clean. Retry as often as you like; every attempt is kept.

Do not open .grading/ before you submit. Pass mark 70/100. Troubleshooting is graded mostly on root cause and evidence; design exercises are graded by rubric only (the grader reports 0/0 tests and the automated row does not apply).

How the local stand-ins work

  • Contact flows: you author flow-language JSON; connect-kit lints the graph (error branches, dead ends, bounded loops, attributes before use, Lambda limits) and simulates call paths with a small interpreter.
  • Lambdas in TypeScript (Node 22) with jest; AWS SDK v3 calls via aws-sdk-client-mock and recorded fixtures (Bedrock, Lex, Customer Profiles, Connect).
  • ServiceNow: a local fake with OAuth client credentials, Table API, pagination, 429 + Retry-After and commit-then-timeout faults.
  • CDK stacks synthesize offline and are checked with aws-cdk-lib/assertions; React with testing-library on jsdom; Python + DuckDB for analytics; Java 21 + JUnit 5 via Maven.
  • Troubleshooting bundles (logs, CTRs, SIP ladders, configs) are generated by make setup.
