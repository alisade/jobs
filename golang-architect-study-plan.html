Principal Golang Architect - Go, Operators, Observability, Agentic AI

6-week plan (plus an optional add-on week) for a 12-month remote contract. Go is front-loaded because everything else depends on it. Weekdays ~2-3h, weekends one long block. Checkboxes save in this browser.

Overview

Helm, ArgoCD, Terraform/CDK, EKS operations and CI/CD are already strengths and are not taught here. The six weeks go to Go itself, operator engineering, Go-side observability, Istio/Kafka depth, and agentic AI built in Go - all converging on one capstone repo.

Capstone: agent-fleet-operator

A Kubebuilder operator (Go, controller-runtime) running on EKS that manages agentic AI workloads through CRDs:

  • MCPServer CRD - deploys an MCP server (built with the official MCP Go SDK) as Deployment + Service + HPA + PDB + Istio AuthorizationPolicy; status conditions, finalizers
  • Agent CRD - deploys a Go agent (official Anthropic Go SDK, Claude on the API or Bedrock) that references MCPServers and a KnowledgeBase
  • KnowledgeBase CRD - RAG ingestion Job into pgvector; the agent queries it through an MCP tool
  • Tasks arrive on Kafka; OpenTelemetry traces span operator, Kafka, agent, LLM and MCP calls; Prometheus metrics + Grafana dashboard
  • Helm chart, CI with envtest, ArgoCD ApplicationSet to two EKS clusters

AI integration fundamentals

Shared across all the study guides. No model training or data science: you call a model over HTTPS and engineer the software around it. Most of it is ordinary API work; the seven areas below are what is different, because an LLM is a probabilistic component, not a deterministic API.
