## Job description

We are seeking a highly experienced AWS AI Architect with strong expertise in Cloud Engineering, DevOps,
and Agentic AI platforms on AWS. The ideal candidate will have hands-on experience building and deploying
scalable cloud-native solutions, automated CI/CD pipelines, and production-grade AI agent systems
leveraging AWS Bedrock AgentCore, MCP integrations, and the Strands framework. Cloud engineering and
DevOps capabilities are the primary focus of this role.

## Key responsibilities

### Cloud Engineering & DevOps (Primary)

- Design build and maintain secure, scalable, multi-account AWS environments
- Develop and manage CI/CD pipelines using GitLab CI/CD and AWS-native deployment services.
- Build, package, and deploy AgentCore workloads as containerized applications using Docker and Amazon ECR.
- Implement Infrastructure as Code (IaC) using AWS CDK and automated CDK deployment pipelines.
- Configure and manage AWS Systems Manager (SSM) for operational automation.
- Design and optimize data persistence using Amazon DynamoDB.
- Implement secure authentication and authorization using OAuth/OBO patterns.
- Apply security and governance policies using AWS Cedar authorization framework.
- Support SCP-based governance controls and production security policies
- Monitor, troubleshoot, and optimize cloud workloads and deployment processes.

### AI Engineering - Agentic AI and AgentOps

- Build AI agents and multi-agent orchestration workflows using the Strands Framework with AWS Bedrock AgentCore Runtime & Gateway
- Experience in AgentOps and Platform operations for AgentCore runtime, Agent registry, MCP integration, OTEL, Ops. Monitoring
- Implement AI observability, operational monitoring, and distributed tracing
- Develop and manage MCP (Model Context Protocol) integrations with enterprise systems and tools.
- Integrate Bedrock foundation models with enterprise applications and APIs.
- Implement AI observability, governance, security, and runtime monitoring.
- Optimize AI agent performance, scalability, and cost efficiency in production environments.
